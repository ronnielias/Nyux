# Nyux 0.1

Nyux 0.1 lexes and parses `.nyux` source, compiles it to stack bytecode, then
executes that bytecode in its Python-hosted VM. It is not a native-code
compiler: the VM and desktop, web, and system interfaces are implemented by
the Python standard library and host operating system.

## Run

From the project directory:

```sh
python3 nyux.py examples/main.nyux
python3 nyux.py --bytecode examples/main.nyux
```

The first command compiles and runs the example. The second also prints the
generated bytecode before executing it. Runtime and syntax errors include the
source line and a Spanish suggestion.

## Examples

```sh
python3 nyux.py examples/app.nyux
python3 nyux.py examples/web.nyux
python3 nyux.py examples/system.nyux
```

- `app.nyux` opens a real 320×340 window with a clickable button. Linux uses
  Tkinter; Windows uses Win32. A graphical session is required.
- `web.nyux` starts an HTTP server on `127.0.0.1:8080`; visit `/` and `/users`.
  The `/users` response is fixed demonstration JSON, not a user-defined handler.
  Stop the server with Ctrl+C.
- `system.nyux` allocates a bounded 64 KiB bytearray in the Nyux process,
  writes and reads a banner, verifies the read, and reports host CPU/platform
  information. It does not boot a kernel or access physical memory.

Some system/desktop operations are intentionally unsupported and return
explicit TODO/errors rather than reporting false success. See [HONEST.md](./HONEST.md)
for the exact current scope and [SPEC.md](./SPEC.md) for language syntax.

## Tests

```sh
python3 -m unittest discover -s tests -v
```

Nyux 0.1 has no third-party Python package dependencies. The GUI example still
requires the platform's Tkinter/Win32 facilities and a graphical session.
